Esta página usa o Meta Pixel (rastreamento de conversão para anúncios) e o Microsoft Clarity (mapas de calor e gravações de sessão, para entender como a página é usada). Os dados de origem da visita (UTMs) ficam salvos no armazenamento local do seu navegador, para identificar o canal que te trouxe até aqui, e podem ser encaminhados ao gateway de pagamento junto com o link de checkout. Os dados de pagamento são digitados diretamente na página do gateway de pagamento; esta página não tem acesso a eles.
